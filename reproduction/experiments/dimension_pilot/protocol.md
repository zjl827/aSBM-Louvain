# Attribute dimension at fixed community signal

This is the 50-, 100-, and 200-dimensional part of Supplementary Section S5. The undirected, loop-free SBM has 1,000 nodes, five communities of 200 nodes, expected average degree 20, and structural ratio $r=4$. Thus $p_{\mathrm{out}}=20/(199\times4+800)$ and $p_{\mathrm{in}}=4p_{\mathrm{out}}$. The grid crosses dimensions 50, 100, and 200 with noise SD 1.5 and 4.

Each of ten independent replicates generates a graph, a $5\times50$ matrix of standard normal community means, and a $1{,}000\times200$ matrix of standard normal residuals. For dimension $D$, the mean matrix is padded with $D-50$ zero columns and the attributes use the first $D$ residual columns. All six conditions within a replicate share the graph, means, and residual prefixes. The population Mahalanobis distances at fixed noise SD are constant across dimensions, while total noise energy increases with dimension.

aSBM-Louvain uses $\beta=1$, initial annealing strength 1, cooling factor 0.8, Louvain resolution 1, relative objective tolerance $10^{-3}$, absolute modularity tolerance $10^{-4}$, and an unchanged community count for three successive updates. It uses full covariance matrices with a $10^{-6}$ diagonal ridge. The aSBM baseline uses full covariance matrices and objective tolerance 1. Both iterative fits use a 1,000-iteration budget and a 300-second soft time limit. Louvain estimates $K$ (at least two). Its partition also serves as a reference for all conditions sharing the graph. Attribute K-means (`nstart=5`, `iter.max=10`) is run on each input. Its estimated-$K$ partition and post-initialization RNG state are shared by both iterative fits.

For replicate `b` from 1 through 10, the graph, means, residual, Louvain, and K-means seeds are `108100000+b`, `108110000+b`, `108120000+b`, `108130000+b`, and `108140000+b`, respectively.

Run `run.R` followed by `analyze.R`. The analysis reads `raw_metrics.csv` and reports score means, sample SDs, available fit counts, and paired ARI differences from dimension 50. Both scripts use `outputs/dimension_pilot` by default. Set `DIM_PILOT_OUTPUT` to use another directory. `DIM_WORKERS` sets the fitting worker count (default 2). `DIM_SMOKE=1` runs one replicate of the grid and should use a separate output directory. The analysis expects the full grid and ten replicates.
